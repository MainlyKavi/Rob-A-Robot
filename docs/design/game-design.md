# Rob a Robot: game design

Status: not started. Fill this in before building features.

## Core loop (solo)

1. Own robots on your base. Each robot earns cash per second.
2. Collect cash, buy more or rarer robots, upgrade them.
3. Unlock more base space / new robot tiers.

## Optional multiplayer

- Stealing robots from other players' bases (with defenses and cooldowns).
- Trading (later, only if it adds to the game).
